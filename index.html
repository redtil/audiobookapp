    Sync your library between devices

    Your book list, the text, where you are and what's finished are saved to a private GitHub repository of yours, so every device shows the same library. Audio isn't synced (it's too big): prepare it on each device, or use “Save audiobook file” and open that file on the other device.

    1. On GitHub, create a new private repository, e.g. audiobook-data.
    2. Create a fine-grained token: choose “Only select repositories” → that repository, and under Repository permissions set Contents to “Read and write”.
    3. Enter both below. Do the same on each device (the same token works).
